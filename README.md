# 📊 Telecom Customer Churn Analysis

A data analytics project focused on understanding customer churn behavior in the telecom industry using Python, Jupyter Notebook, and Tableau.  
The project analyzes customer behaviour, service usage and billing patterns to identify factors contributing to customer churn and support business decision-making.

# 🚀 Project Highlights

- Performed Exploratory Data Analysis (EDA) on telecom customer data
- Identified key churn indicators and customer retention patterns
- Analyzed customer demographics, tenure, contracts, and payment behavior
- Built an interactive Tableau dashboard for business insights and visualization
- Generated data-driven recommendations to improve customer retention strategies

---

# 🛠️ Tools & Technologies

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Tableau

---

# 📈 Key Insights

- Month-to-month contract customers showed higher churn rates
- Customers with shorter tenure were more likely to churn
- Higher monthly charges were associated with increased churn probability
- Electronic check payment users demonstrated higher churn behavior
- Long-term contract customers showed better retention patterns
